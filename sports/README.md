Currently contains 2 Python programs that display sports info on a 800x600 Kindle screen using data
from ESPN's internal API; MLB.py shows an overview of the first 10 games and displays info using 
the built in "eips" command on Kindles while WNBA.py shows a detailed overview of one game including
score, time, team stats, and the most recent play rendering info using the Pillow library. The WNBA
program should be 100% compatible with NBA data. 

Note: Higher refresh intervals run the risk of ESPN detecting abnormal activity and potentially
IP-banning you from pulling data
